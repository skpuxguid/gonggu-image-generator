# 공동구매 이미지 생성기

배경이 포함된 제품 이미지 1장을 넣으면
1. 슬롯 4개(A/B/C/D) 사이즈로 크롭·스케일해 **컴포넌트 4개**를 만들고
2. 템플릿 UI 화면(빅배너/공동구매/추천/상세)을 **복사해서 기존 이미지 인스턴스를 새 컴포넌트로 교체**한 화면을 바로 보여주는 Figma 플러그인.

## 설치 (개발용)
1. Figma 데스크톱 앱 → 메뉴 → Plugins → Development → **Import plugin from manifest...**
2. 이 폴더의 `manifest.json` 선택
3. Plugins → Development → 공동구매 이미지 생성기 실행

## UI 미리보기용 템플릿 (마스터 Sample)
UI 화면(공동구매/추천/상세/빅배너)과 템플릿 이미지 컴포넌트가 **모두 들어 있는 Sample 프레임 1개**를 기준으로 미리보기를 만든다.
- 템플릿 컴포넌트: 슬롯 크기(390², 275², 162×250, 720×460)이고 **텍스트가 없는** 컴포넌트
- UI 화면: 같은 프레임 안에 있는 **가로 360** 프레임
- 우선순위: **직접 지정한 Sample > 현재 페이지 자동 감지**
  - 직접 지정: Sample 프레임(또는 그 안의 레이어)을 선택하고 `이 Sample을 UI 템플릿으로 지정` → 파일에 저장됨
  - 자동 감지: **UI 화면이 가장 많은 Sample이 딱 하나일 때만** 사용. 같은 점수가 둘 이상이면 고르지 않고 안내만 한다. UI 화면이 3개 이상인 완전한 Sample이 하나로 정해지면 파일에 기억해 두어, 다른 페이지에서 실행해도 UI 미리보기가 나온다.
- **이미지를 가져오려고 선택한 레이어에서는 템플릿을 추정하지 않는다.** (제품별 Sample이 많아 엉뚱한 Sample이 잡히는 문제 방지)
- 패널의 "템플릿" 영역에 쓰고 있는 프레임 이름, 잡힌 컴포넌트/화면이 표시되고 `템플릿 위치 보기`로 그 프레임으로 이동할 수 있다.
- UI 화면이 3개 미만인 Sample을 쓰면 경고가 뜬다 (예: 빅배너 화면만 있는 제품별 Sample).
- 못 찾으면 상단에 주황색 안내가 뜨고 컴포넌트만 만든다.
- 패널 제목의 버전(`v3.0`)이 보이면 최신 버전이 실행 중인 것이다.

## 사용
1. `이미지 파일 추가` 또는 Figma에서 이미지를 선택하고 `Figma 선택 가져오기`
2. 이미지 이름을 `브랜드명_상품명` 형식으로 입력(= 컴포넌트 이름 앞부분, 입력창 아래에 결과 이름이 미리 표시됨), 오브젝트 유형 선택, **배경 종류**(투명/흰색/기타) 확인 — 파일을 넣으면 자동 판별되며 바꿀 수 있다
3. 미리보기에서 오브젝트(제품) 영역을 드래그로 지정 (투명/단색 배경이면 자동 감지)
4. `컴포넌트 생성 + UI 미리보기`
   - 컴포넌트: `{이름}1`, `{이름}2`, `{이름}3`, `{이름}_bigbanner`
   - UI 미리보기: 템플릿 화면의 **복사본**에서 템플릿 이미지 인스턴스만 새 컴포넌트로 교체 (원본 화면은 건드리지 않음)
5. 결과 창의 경고(여백 부족, UI 텍스트 영역 침범)와 교체 건수를 확인

가이드(`_guides` 그룹, 안전 영역=초록 / UI가 가리는 곳=빨강)는 컴포넌트 밖에 따로 놓이고 잠겨 있어서 UI 미리보기에는 나오지 않는다.
- 결과물(컴포넌트)을 지워도 가이드는 남지만, **플러그인을 열 때와 생성할 때 짝이 없는 가이드는 자동으로 지운다.**
- 바로 지우려면 패널의 `가이드 모두 지우기` 버튼 (현재 페이지의 `_guides` 그룹 전부 삭제).
- 직접 지우려면 레이어 패널에서 `_guides` 검색 → 선택 → 우클릭 Unlock(⌘⇧L) → 삭제.

## 슬롯
| 슬롯 | 컴포넌트 | 크기 | 쓰이는 UI | 처리 |
|---|---|---|---|---|
| A | `이름1` | 390×390 | 공동구매 Deal 카드(가로 29~361 노출), 추천 카드(가로 69~321 노출) | 안전 영역 기준 크롭·스케일 |
| B | `이름2` | 275×275 | 상세 썸네일(360으로 확대 표시) | **흰색 배경** + 제품을 가운데(여백 27.5px)에 맞춤 |
| C | `이름3` | 162×250 | 공동구매 D-3 오픈예정 카드 | 안전 영역 기준 크롭·스케일 |
| D | `이름_bigbanner` | 720×460 | 빅배너(가운데 가로 180~540만 노출) | 안전 영역 기준 크롭·스케일 |

## B(275×275) 흰 배경 규칙
컴포넌트 배경을 흰색으로 채우고, 입력 이미지의 배경 종류에 따라 다르게 처리한다.
- **투명 PNG**: 제품을 220×220 안에 가운데로 맞춰 넣음 (흰 배경 위에 얹힘)
- **흰 배경 이미지**: 이미지가 슬롯을 덮도록 스케일, 제품을 가운데로. 여백이 부족하면 경고
- **배경이 있는 이미지**: `2번(상세) 배경 제거` 체크(기본 켜짐)면 이미지 테두리에서 배경색과 비슷한 부분을 지워(투명) 흰 배경 위에 올린다. **단색 배경에서만 믿을 만하고**, 스튜디오 사진처럼 빛무늬·그림자가 있는 배경은 제품(특히 흰색)이 같이 지워질 수 있다. 그런 사진은 누끼(투명 PNG)가 필요하다 ((가) 버전 범위). 체크를 끄면 가운데 크롭만 하고 경고를 띄운다.

## 이름 규칙
`bigbanner`(또는 `빅배너`)는 720×460 컴포넌트에만 붙는다. Figma에서 가져온 이름에 이 글자가 들어 있으면 자동으로 지우고 `1/2/3`을 붙인다.

## 보정 방법
`code.js` 맨 위의 `SLOTS`(슬롯 크기, 안전 영역, UI 오버레이 가이드)와 `TYPES`(유형별 배율)만 수정하면 된다.
- 안전 영역: A/C는 Figma `[운영]공동구매_배송상품_동원` 프레임(참치캔)에서 측정, **D는 추정**
- 가이드(UI가 가리거나 잘라내는 영역): Sample 화면의 UI 구조에서 측정
- 유형별 배율은 추정치 → 미리보기 화면을 보면서 보정

## 한계
- 배경이 이미지에 구워져 있어 오브젝트만 따로 옮길 수 없다. 이미지 전체를 크롭·스케일하므로
  원본에 여백이 부족하면 목표 위치에 못 맞추고 경고만 띄운다.
- 자동 감지는 투명 배경이나 단색 배경에서만 동작한다. 사진 배경은 드래그로 영역을 지정한다.
- 템플릿 컴포넌트와 UI 화면은 같은 프레임(또는 섹션) 안에 있어야 하고, 페이지에 바로 놓인 것은 인정하지 않는다(이전 결과물과 구분).
- 미리보기는 "템플릿 컴포넌트의 인스턴스"만 교체한다. 그 화면에 템플릿 이미지가 없으면 교체 건수 0으로 표시된다.
- 복사 → 인스턴스 교체는 실제 Figma 파일(Sample 프레임)에서 시험해 동작을 확인했다. 플러그인 패널(UI)과 이미지 업로드는 가짜 Figma API와 브라우저로 검증했다.
